# PMIS – Smart Internship Management System

A web-based platform developed for the **Prime Minister Internship Scheme (PMIS)** to connect internship seekers, companies, and administrators.

## Features

- **Student Module:** Registration, login, profile management, and application tracking.
- **Company Module:** Registration, login, and candidate profile management.
- **Admin Module:** Manage internship seekers, view candidate profiles, and manage internship matches.

## Technology Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite

## Installation and Setup

**Prerequisites:** Python 3.x and Git.

1. Clone the repository:

```bash
git clone https://github.com/Himanshu-1708/PMIS.git
```

2. Navigate to the project folder:

```bash
cd PMIS
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

Open the local URL displayed in the terminal.

## Database

The application uses SQLite for database management.
